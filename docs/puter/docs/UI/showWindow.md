# ![Image](/./assets/img/function.svg)`puter.ui.showWindow()`

 Websites Puter Apps Node.js Workers

---

The `showWindow` method allows you to show the window of your application.

## Syntax

```javascript
puter.ui.showWindow()
```

## Parameters

None.

## Return Value

None.

## Example

```html
<html>
<body>
    <script src="https://js.puter.com/v2/"></script>
    <script>
        puter.ui.showWindow();
    </script>
</body>
</html>
```
