# ![Image](/./assets/img/function.svg)`puter.ui.hideWindow()`

 Websites Puter Apps Node.js Workers

---

The `hideWindow` method allows you to hide the window of your application.

## Syntax

```javascript
puter.ui.hideWindow()
```

## Parameters

None.

## Return Value

None.

## Example

```html
<html>
<body>
    <script src="https://js.puter.com/v2/"></script>
    <script>
        puter.ui.hideWindow();
    </script>
</body>
</html>
```
