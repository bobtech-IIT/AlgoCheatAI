In this guide, you'll learn how to use [Puter](https://puter.com/) to deploy your React app for free. Puter is a cloud operating system in your browser with a [web hosting](/static-hosting/) feature allowing you to host your website easily.

## Deploying your React App

### Step 1: Prepare Your Site

Inside your React project folder, simply run the build command to generate your website files:

```javascript
npm run build
```

After the build completes, your website files will be in the `dist` folder. This `dist` folder is what you'll upload to Puter.

![React static output folder](/assets/img/react/output.webp)

### Step 2: Upload Your Site to Puter

1. Go to [Puter.com](https://puter.com)
2. Drag the `dist` folder from your local machine into the Puter cloud desktop

![Uploaded files](/assets/img/react/drag.webp)

1. Open the folder to verify that your React app is uploaded

![Uploaded files](/assets/img/react/uploaded.webp)

### Step 3: Publish Your React App

1. In the same folder, right-click and select  **Publish as Website**

![Context Menu: Publish as Website](/assets/img/react/publish-website.webp)

1. Choose your free subdomain (e.g., `yoursite.puter.site`) and click  **Publish**

![Choose free subdomain](/assets/img/react/subdomain.webp)

1. Congratulations, you have successfully published your React app!

![Publish website](/assets/img/react/published.webp)
