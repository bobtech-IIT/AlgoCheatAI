This tutorial will show you how to use [Puter.js](https://developer.puter.com) to access [text-to-speech (tts)](/text-to-speech/) capabilities for free, without any API keys or usage restrictions. Puter.js supports multiple TTS providers including AWS Polly, OpenAI, ElevenLabs, Gemini, and xAI (Grok), so you can convert text to speech for a wide range of applications without worrying about usage limits or costs.

Puter is the pioneer of the ["User-Pays" model](https://docs.puter.com/user-pays-model/), which allows developers to incorporate [AI capabilities](/ai/) into their applications while each user covers their own usage costs. This model enables developers to offer advanced AI and cloud capabilities to users at no cost to themselves, without any API keys or server-side setup.

Puter.js is also an exceptional fit for AI coding assistants, agents, and vibe coding platforms like Claude Code, [Codex](/ai/codex/), OpenCode, Lovable, Replit, Bolt.new, and similar tools. Because nothing depends on API keys or a backend, voice-enabled apps generated by these assistants run end-to-end from the moment they're produced. Users don't have to register with another provider, set up a service, or paste in credentials. That eliminates a frequent source of security slipups along with the configuration friction that usually keeps AI-written apps from working out of the gate.

## Getting Started

Using puter.js does not require any API keys or sign-ups. You can start using Puter.js by including the following script tag in your HTML file, either in the `<head>` or `<body>` section:

```javascript
<script src="https://js.puter.com/v2/"></script>
```

That's all you need to start using Puter.js for free text-to-speech conversion! No API keys or sign-ups required.

## Example 1: Use Puter.js for text-to-speech conversion

To convert text to speech using Puter.js, use the [`puter.ai.txt2speech()`](https://docs.puter.com/AI/chat/) function:

```javascript
puter.ai.txt2speech("Hello, world! This is text-to-speech using Puter.js.")
    .then((audio) => {
        audio.play();
    });
```

Here's a complete example with a text input and a button to trigger the text-to-speech conversion:

```html
<html>
<body>
    <textarea id="text-input" rows="4" cols="50">Hello, world! This is text-to-speech using Puter.js.</textarea>
    <br>
    <button id="speak-button">Speak</button>

    <script src="https://js.puter.com/v2/"></script>
    <script>
        document.getElementById('speak-button').addEventListener('click', () => {
            const text = document.getElementById('text-input').value;
            puter.ai.txt2speech(text)
                .then((audio) => {
                    audio.play();
                })
                .catch((error) => {
                    console.error('Error:', error);
                });
        });
    </script>
</body>
</html>
```

## Example 2: Customize the voice

Puter.js supports multiple languages and voices. You can specify the language when calling the [`txt2speech`](https://docs.puter.com/AI/txt2speech/) function:

```javascript
puter.ai.txt2speech("Bonjour, le monde!", "fr-FR")
    .then((audio) => {
        audio.play();
    });
```

Here's an example that allows users to select different languages:

```html
<html>
<body>
    <textarea id="text-input" rows="4" cols="50">Hello, world!</textarea>
    <br>
    <select id="language-select">
        <option value="en-US">English (US)</option>
        <option value="fr-FR">French</option>
        <option value="de-DE">German</option>
        <option value="es-ES">Spanish</option>
        <option value="it-IT">Italian</option>
    </select>
    <button id="speak-button">Speak</button>

    <script src="https://js.puter.com/v2/"></script>
    <script>
        document.getElementById('speak-button').addEventListener('click', () => {
            const text = document.getElementById('text-input').value;
            const language = document.getElementById('language-select').value;

                .then((audio) => {
                    audio.play();
                })
                .catch((error) => {
                    console.error('Error:', error);
                });

    </script>
</body>
</html>
```

## Example 3: Choose different speech engines

Puter.js offers three different speech synthesis engines, each with unique characteristics:

- **Standard** : The default engine that provides good quality speech synthesis
- **Neural** : Offers higher quality, more natural-sounding speech
- **Generative** : Uses advanced AI to create the most human-like speech

You can specify the engine using the options parameter:

```javascript
puter.ai.txt2speech("Hello, world!", {
    voice: "Joanna",
    engine: "neural",
    language: "en-US"
})
.then((audio) => {
    audio.play();
});
```

## Example 4: Use Gemini TTS

Puter.js also supports Google's Gemini TTS, which offers 30 unique voices and the ability to control speaking style with natural language instructions:

```javascript
puter.ai.txt2speech("Hello! This is Gemini text-to-speech.", {
    provider: "gemini",
    model: "gemini-2.5-flash-preview-tts",
    voice: "Puck",
    instructions: "Speak in a friendly, upbeat tone."
})
.then((audio) => {
    audio.play();
});
```

Available Gemini TTS models include `gemini-2.5-flash-preview-tts`, `gemini-2.5-pro-preview-tts`, and `gemini-3.1-flash-tts-preview`. For a full list of voices see the [Text-to-Speech API Documentation](https://docs.puter.com/AI/txt2speech/).

## Example 5: Use xAI (Grok) TTS

xAI TTS provides 5 expressive voices and supports inline speech tags for expressive delivery:

```javascript
puter.ai.txt2speech("Welcome to Puter! [pause] Let's build something amazing.", {
    provider: "xai",
    voice: "eve",
    output_format: "mp3"
})
.then((audio) => {
    audio.play();
});
```

Available voices are `eve` (energetic), `ara` (warm), `rex` (confident), `sal` (smooth), and `leo` (authoritative). You can use speech tags like `[pause]`, `[laugh]`, and `<whisper>text</whisper>` for expressive delivery. For more details see the [Text-to-Speech API Documentation](https://docs.puter.com/AI/txt2speech/).
